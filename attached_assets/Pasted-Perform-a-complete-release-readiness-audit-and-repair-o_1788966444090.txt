## Phase 5: Diagnose database migrations and deployment

Inspect the deployment logs and identify the first real error behind:

“Failed to validate database migrations.”

Determine whether the cause is:

- Missing production database environment variables.
- Database connection failure or timeout.
- Migration history mismatch.
- Missing migration files.
- Modified or deleted applied migrations.
- A migration lock.
- A migration command waiting for interactive input.
- A migration command that never exits.
- Incorrect deployment configuration.

Fix the issue safely:

- Use a noninteractive, one-shot migration command.
- Ensure the build command finishes.
- Ensure migrations finish and exit successfully.
- Ensure the production start command is separate from build and migration commands.
- Do not use watch mode during deployment.
- Do not reset, drop, truncate, or recreate the production database.
- Do not delete or rewrite previously applied migration history.
- Do not run destructive schema changes without stopping and explaining the exact risk.

If the production database state is ambiguous, preserve the data and report the safe repair required instead of forcing a reset.
